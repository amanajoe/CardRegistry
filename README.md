# CardRegistry - Collectible Trading Card Authentication System

A blockchain-based collectible trading card authentication and ownership system built on Stacks, providing secure and transparent records of trading card authenticity and ownership transfers.

## Overview

CardRegistry enables collectors to authenticate their trading cards with detailed game and edition information while maintaining secure ownership records and facilitating card transfers in the collectibles market.

## Features

- Trading card authentication with game series and edition tracking
- Card description and rarity level assessment
- Authentication status management and ownership verification
- Card ownership transfer functionality
- Comprehensive input validation and security measures

## Smart Contract Functions

### Public Functions
- `authenticate-trading-card`: Authenticate trading cards with detailed information
- `transfer-card-ownership`: Transfer card ownership to new collectors

### Read-Only Functions
- `get-trading-card`: Retrieve trading card authentication information
- `get-card-collector`: Get card collector information

## Usage

Authenticate trading cards with detailed game and edition information, track rarity levels and authentication status, and transfer ownership when trading. Build a comprehensive card collection registry.

## Security

- Collector verification for card ownership transfers
- Comprehensive input validation for all card parameters
- Status-based transfer restrictions to ensure proper workflow
- Card name and description length validation for data integrity
